## Important distinctions

- A Goal states intent. An Outcome states a result or effect.
- A Principle applies a general property. A Requirement applies a need to a specific system.
- A Constraint limits the architecture or its change.
- A Capability is an ability. A Value Stream organizes activities around stakeholder value.
- A Process organizes a sequence. A Function groups behavior by selected criteria.
- An Interaction is collective behavior. A Collaboration is the participating active structure.
- A Service is exposed behavior. An Interface is its point of access.
- A Business Object is a business concept. A Data Object is structured for automated processing.
- A Representation makes information perceptible. An Artifact is an implementation or operational data item.
- A Work Package contains actions. A Deliverable is its defined result.
- A Plateau represents a state. A Gap represents a difference between states.
