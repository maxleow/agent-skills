# STE writing record

The requested target is an approximately **80% application of ASD-STE100 plain writing**.
Use the shared [writing profile](../writing.md) for the combined skill.
It is not a measured compliance score.

The skill uses short sentences, direct commands, and consistent terms.
Instructions use one main action per sentence.
Conditions precede the actions that depend on them.
Prose uses a maximum of 20 words per sentence where practical.

These choices follow the [official STE guidance](https://www.asd-ste100.org/STE_faq.html).
The [Issue 9 procedure rules](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf) give the sentence length limit.

## Terms

| Term | Meaning in this skill |
| --- | --- |
| Model | The elements, relationships, and membership facts |
| Layout | The positions, dimensions, and connector paths |
| Notation | The domain rules for symbols and relationship marks |
| Style | The visual choices that do not change model meaning |
| Canvas | The diagram area |
| Element | An object in the model |
| Connector | A visible line that represents a relationship |
| Port | An attachment point on an element |
| Preset | A reusable set of visual values |
| Renderer | A tool that makes a preview from the source |
| Asset | An image or other resource used in the output |

Technical verbs include `embed`, `export`, `resize`, `parse`, and `render`.
File formats, XML names, paths, and code identifiers keep their required spelling.
This glossary defines project terms.
It does not certify their use under every STE rule.

## Review limits

Sentence length checks measure only part of the writing style.
Review the current prose. Do not reuse an earlier sentence-length result after changes.
This review excludes tables, metadata, and code.
The review does not include a complete dictionary, part-of-speech, and approved-meaning audit.
Do not claim a verified 80% score or certified compliance.

The [official download page](https://www.asd-ste100.org/STE_downloads.html) explains the limits of AI compliance claims.
